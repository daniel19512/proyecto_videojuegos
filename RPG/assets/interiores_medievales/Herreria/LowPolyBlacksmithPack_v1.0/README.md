# Low Poly Blacksmith Pack (Free)
by reodesuxz

25 low poly blacksmith and forge models: anvil, forge, weapons, tools and workshop props.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Blacksmith_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 2268 triangles for all 25 models (32-340 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
